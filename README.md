# Lexon

Indonesian legal AI workspace — Chat, Tabular Review, and DOCX drafting over a
firm's own documents, with verifiable citations.

| Path | Contents |
|---|---|
| `docs/specs/` | Authoritative documents: [Technology Stack](docs/specs/LEXON-01-TECHNOLOGY-STACK.md), [System Architecture](docs/specs/LEXON-02-SYSTEM-ARCHITECTURE.md), [Design System](docs/specs/LEXON-03-DESIGN-SYSTEM.md) |
| `docs/briefs/` | Clean feature briefs, the input for each superpowers brainstorming session ([index](docs/briefs/README.md)) |
| `docs/superpowers/` | Specs and plans produced by superpowers |
| `docs/references/` | Official documentation and llms.txt index per technology ([README](docs/references/README.md)) |

Application folders (`backend/`, `frontend/`, `shared/`, …) are created by the
F0 Foundation slice.

Clean-room research lives on the orphan branch `contaminated`, which is never
merged and must not be checked out by implementers (see `AGENTS.md`).
