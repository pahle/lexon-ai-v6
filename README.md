# brief-generator — clean-room handoff kit

**Implementers (human or agent) must not read this branch.** It holds the
dirty side of Lexon's clean room: research about the AGPL-3.0 reference
product, the brief generator's working state, and implementation reviews.
It is an orphan branch and is never merged into `main`.

**New session or new model? Start with `STATE.md`, then `AGENTS.md`.**

| Path | Contents |
|---|---|
| `STATE.md` | Current status, next action, pending questions, follow-ups, decision log, lessons |
| `AGENTS.md` / `CLAUDE.md` | Role, hard rules, workflow loop for the brief generator |
| `playbooks/` | Procedures: write a brief, support the implementer, review an implementation, git and PRs |
| `notes/` | Research log (pinned reference commit), feature inventory → slices, per-slice behavior notes |
| `reviews/` | Implementation reviews per slice |
| `reference/mike-diagrams/` | Excalidraw diagrams of the reference, provided by the product owner |
