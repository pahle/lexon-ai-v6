# Lexon Logo, Final 2026

Final logo package for Lexon, a Legal AI Workspace for Indonesia.

Start here:
- Use the logo: `01_VECTOR/LEXON-wordmark-ink.svg` (light backgrounds) or `LEXON-wordmark-cream.svg` (dark).
- See the rules: `06_GUIDELINES/BRAND-GUIDELINES.md` or the PDF.
- Build the website: `07_DEVELOPER_HANDOFF/INSTALL-NEXTJS.md`.
- Overview: `04_PREVIEW/logo-sheet.png`, plus application mockups in `04_PREVIEW/` (website, dashboard, mobile and favicon, stationery, social, legal document, palette).
- Marks (L in a circle, square or rounded square): `01_VECTOR/marks/`, overview in `04_PREVIEW/preview-marks.png`.
- Colors: Royal Seal palette (ink `#1F1717`, seal `#7A1F2E`, parchment `#F6EFE2`), tokens in `05_BRAND_SYSTEM/`.
- Logo versions by size: wordmark 200 px and up, compact wordmark 128 to 199 px, monogram 64 px and up, small monogram 40 to 63 px, micro mark 16 to 39 px.

Open items before public launch (trademark search, typeface licensing, print proof, user recognition test) are listed in section 9 of the guidelines.
