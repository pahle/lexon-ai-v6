The app resolves the client address from `X-Forwarded-For` through `AUTH_TRUSTED_PROXIES` (`resolveClientAddress`) and Better Auth's own limiter is disabled (`rateLimit.enabled: false`), so R1e does not apply here. Caddy gets `ipv4_address` `.250` of the edge subnet (dynamic addresses start at `.2` and collided). E2E stacks pick a /24 in 10.200-10.249.
