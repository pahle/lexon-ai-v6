# F3 requirement and evidence index

This indexes the implemented assertions against the [brief](../briefs/F3-ai-run-engine.md), its seven flows, and the owner's corrections. It is not a claim that every gate passed at the current head. Exact commands, revisions, failed runs, and deferred checks remain in [F3 acceptance evidence](F3-acceptance.md). The [approved design](../superpowers/specs/2026-11-05-f3-ai-run-engine-design.md) and owner amendments replace the brief's erroneous per-step usage and scheduled-eval wording.

Model calls are attempts with unique receipts/accounting; logical step and tool effects are effectively once. Unknown attempts retain reservations. Real evals are manual only. Actual OpenRouter setup, smoke, calibration, paid execution, and post-merge hosted activation remain deferred. Production region approval is P8, and customer quotas/reconciliation are F17.

## The seven system flows

| Flow                | Assertion path                                                                                                                                                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Happy path       | Atomic start in `ai-run-start`; actual persisted generation in `ai-execution`; real outbox/dispatcher/worker latency in `ai-hop-latency`.                                                                                                     |
| 2. Budget exceeded  | `ai-attempts` and `ai-execution` retain partial output, truthful usage, and no successor/model call after exhaustion.                                                                                                                         |
| 3. Cancel streaming | `ai-cancel` plus SDK replay in `ai-execution`: abort, one durable partial, terminal closure, and no late publication.                                                                                                                         |
| 4. Approval         | `ai-approval` and `ai-execution`: exact hash, one decision, one transactional effect, rejected history, fresh resume, and current permission checks.                                                                                          |
| 5. Crash            | `ai-worker-crash`, `ai-storage`, and recovery queue/concurrency assertions: old fence blocked, unknown reservation retained, replacement attempt distinct, one committed result. Historical intermittent failures remain in acceptance notes. |
| 6. Blocked model    | Gateway unallowlisted/prerequisite refusal tests assert zero fetch; actual outgoing routing tests assert only reviewed Azure US and mandatory privacy fields.                                                                                 |
| 7. Cross-tenant     | `ai-storage`, `run-authorization`, `ai-step-concurrency`, and `ai-queue-routing` assert foreign/no-context isolation and no foreign receipt, mutation, successor, or audit authority.                                                         |

## Owner corrections and final gates

- Global admission is 24 and per-organization admission is 6; [capacity tests](../../backend/test/integration/ai-capacity.spec.ts) check organization B can start when A is full, refusals create no run/outbox/slot, and terminal release occurs once. Runtime configuration remains SELECT/INSERT only; changes to fixed capacity require a migration.
- [Queue/concurrency tests](../../backend/test/integration/ai-step-concurrency.spec.ts) cover tenant job context, no lookup-based tenant discovery, one current sequence, stale/terminal no-op, and continuation/receipt atomicity. Infrastructure/domain and SDK import restrictions remain lint fixtures, including denial of production imports through the SDK test helper.
- [Attempt and execution tests](../../backend/test/integration/ai-attempts.spec.ts) separate persisted reservations from reported usage, enforce SDK retries zero at the gateway, and preserve generation IDs/partial output on recovery. The estimator must be calibrated before F8 large-context use.
- [Approval execution tests](../../backend/test/integration/ai-execution.spec.ts) check initiating-user-only decisions and access loss at decision/resume. [Tool recovery tests](../../backend/test/unit/tool-recovery.spec.ts) require explicit write idempotency mode and prohibit blind re-execution of undecidable external operations.
- Stream MAXLEN 1024, 24 active/6 retained terminal slots, 3600-second terminal TTL, 250 ms total publication deadline, oldest-terminal eviction, and the 6 MiB slot bound remain fixed. [Hop samples](F3-hop-latency.json) preserve the earlier contended samples as invalid gate evidence; current uncontended gate and environment are recorded separately.
- Local package, tooling, mutation, and Compose results are listed with revisions in [acceptance evidence](F3-acceptance.md). The first Linux CI at `d4cbea0` passed Compose 55/55, all 82 baseline checks and the platform axe path; the earlier five Darwin/arm64 visual failures remain historical failures. Corrected-head Linux CI is still required. Baselines stay unchanged.
- Final whole-branch review, exact reviewed-head Linux CI, final PR publication, and the explicit owner-deferred real-model checks are separate gates. This index neither approves them nor relabels an unexecuted check as green.
