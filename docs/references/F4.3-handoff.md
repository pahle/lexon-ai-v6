## Decisions and open issues

- **Scale check (Task 3):** the gate forces index plans and asserts the expected index names, because `count(*) OVER ()` makes a Seq Scan the natural plan at 10k rows. Migration 0040's search functions were split into search and no-search branches so that a generic plan can use the trigram indexes.
- **Provisioning 404s:** they also cover active organizations, not only unknown or cancelled ones. This is wider than spec §4.4a; flagged to the owner.
- **Last-admin race:** the losing call may get 401 AUTH_REQUIRED (deadlock retry) instead of 409. The 409 is pinned by a unit test of `assertNotLastAdministrator`.
- **Admin without 2FA:** the 403 is covered only in integration (the code is `AUTH_2FA_REQUIRED`), because E2E admin setup forces 2FA.
- **Limiters:** they are required constructor arguments, consumed after re-auth. Verification resend shares the user's own `verification-resend` key through `emailLimitKey` and `correlationSecret`, which is the audit HMAC secret.
- **Account invitations:** the token is ignored while sign-up is open. The new invitation E2E specs run in shard 3, because shard 1 must keep first-admin setup unused.
- **Members audit:** written for every found organization, provisioning included.
- **Kit:** there is no `axe-core` in the frontend. Real axe and contrast checks are planned for Task 19 in Playwright. Adding it as a devDependency would need owner approval.
- **shadcn checkbox:** added with no package.json change, so that approval point did not trigger.
- **Moved to Task 16:** the sidebar swap (Accounts/Organizations), the `/platform/provisioning` redirects, switching `/platform/accounts` from the old Account status form to `AccountsPage`, and deleting the old platform components.
