# F4.1 Brand Refresh and Chat Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (the owner chose inline execution by the main agent). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild every Lexon screen on brand v4.1 and the approved chat experience without changing F0–F4 behavior, and lock an owner-approved screenshot set as Linux goldens.

**Architecture:** The old visual sets are retired first, because every token change would break them. Tokens, fonts, and marks change next, so the app is coherent from the start; then the shell, auth, chat, and Settings are restyled screen by screen. The thinking indicator is a pure sequencing engine plus a thin SVG renderer. A new `brand-visual` Playwright project replaces the F2.1 and F4 visual sets.

**Tech Stack:** Next.js 16.4.3, React 19.3.1, Tailwind 4.3.3, shadcn 4.23.0 (`base-nova`), `@assistant-ui/react` 0.15.33, Better Auth, Drizzle SQL migrations, Zod 4.6.7, Vitest 5.0.5, Playwright 1.64.1, Stryker 10.1.1.

**Spec:** [`docs/superpowers/specs/2026-11-15-f4.1-brand-refresh-design.md`](../specs/2026-11-15-f4.1-brand-refresh-design.md) (approved 2026-11-15). Section numbers below (§) refer to it.

## Review Focus

Inputs the spec implies but that are easy to miss. Each has a test in the named task.

1. **A display name with one word, extra spaces, or non-Latin characters** in the greeting and the initials tile: the greeting uses the first whitespace-separated word; initials never render empty (Tasks 11, 18).
2. **A job title of exactly 80 characters or a very long organization name** in the 16rem sidebar: text truncates with an ellipsis and never widens the sidebar (Tasks 11, 14).
3. **A run that ends within the first second, or ends while the tab is hidden:** the answer shows the static mark and "Answer complete" is announced once; no animation is left running (Tasks 25, 26).
4. **Clicking a starter pill when the composer already has text:** the template replaces nothing silently; the existing text is kept and the template is appended on a new line, with the first placeholder selected (Task 20).
5. **Switching the OS to reduced motion while an answer is running:** the indicator becomes the static mark immediately and stays static (Task 25).
