1. **Phase A:** agent changes only tests for that one rule, then stops. The
   controller checks the full changed/untracked file set against an explicit
   test-only allowlist and verifies production file hashes are unchanged.
2. **Controller RED:** the controller itself runs the covering test, records
   command, source/test hashes, actual output and exit status, and confirms an
   expected behavior assertion failure. Setup, import, typing or fixture errors
   are not qualifying REDs. If existing behavior already passes, record regression
   coverage and authorize no production change for that rule.
3. **Phase B:** only after the recorded RED does the controller authorize the
   minimal implementation for that rule, with an explicit production path scope.
   New rules/helpers/validation require their own Phase A and controller RED;
   an earlier broad report-shape failure does not authorize them.
4. **Controller GREEN:** agent stops again; controller inspects the diff and
   independently reruns/records the covering test. Repeat per rule. Keep a
   versioned rule/phase evidence manifest and immutable output logs in ignored
   workflow records; reports reference the controller's evidence.

A production change without a recorded controller-observed RED for that rule
is reverted. Preserve an audit snapshot of the unauthorized diff and report
what happened; do not relabel later tests as earlier RED evidence. No instruction-only
approval, agent-reported test result, or retrospective exception substitutes for
these gates. Fresh per-task spec/quality reviews and final whole-branch review
remain required. Task 17 local smoke and Task 19 self-review follow the 2026-11-13 standing instruction below; final owner review remains at PR handoff.

## Review Focus

1. Request succeeds but its HTTP response is lost: retry returns the same message/run; conflicting reuse and retry after deletion cannot recreate content (Tasks 6, 11).
2. A stale tab changes branch while another tab is generating: viewed leaf uses last committed explicit selection, but the run keeps its original context path (Tasks 6, 9, 10).
3. JSON-escaped/Unicode input and fragmented provider frames: byte limits, complete framing, summary classification and reservation bounds remain correct (Tasks 2, 4, 7).
4. Proxy-held sockets and concurrent reconnects: the newest connection works, oldest eviction is owner scoped, buffers stay bounded, and no subscription/lease leaks persist (Tasks 8, 10, 18).
5. Delete races with the last model chunk or a delayed title: no content returns, usage survives once, capacity returns once and completion audit is once (Tasks 3, 11, 12).
